# SM Flowers — редактор сайта по блокам

Админка должна показывать контент не единым списком, а отдельными блоками сайта.

## 1. Главная
- Фото: главная фотография / hero.
- Тексты: все надписи первого экрана.
- Не показывать здесь фразу «Каждый букет существует в единственном экземпляре».

## 2. О студии
- Тексты блока «О студии».
- Фото-контролы показываются только если у блока есть реальные управляемые фото.

## 3. Коллекции
- Фотографии каждой коллекции.
- Тексты и подписи коллекций.

## 4. Букеты
- Фото каждого букета.
- Название, описание, цена.
- Видимость и порядок.

## 5. Жизнь студии
- Все фотографии этого блока.
- Тексты блока.
- Instagram @smflowers.msk и ссылка.
- «Каждый букет существует в единственном экземпляре».
- Не показывать и не редактировать здесь «Авторский букет» и «Розовое облако».

## 6. Студия / Контакты
- Адрес.
- Ссылка на карту.
- Текст ссылки на карту.
- Время работы.
- Телефон и социальные ссылки.

## UX
Каждый блок открывается отдельно. Внутри блока сначала фото (если они есть), затем тексты. Сохранение каждого элемента должно работать независимо. Интерфейс должен быть удобен на телефоне и компьютере.

Эта спецификация не меняет существующую рабочую админку до отдельного безопасного подключения UI.
